# Asset attribution

## Original Recall assets — CC0-1.0

`public/wallpaper.svg` and `public/icons/icon16.png`, `icon48.png`, and `icon128.png` are original programmatically drawn assets created for this project. The wallpaper depicts layered mountain ridges, haze, and forest silhouettes; it is not a downloaded photo or a copy of the supplied reference. The author dedicates these original assets to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

## Lucide icons — ISC

The interface uses bundled icons from `lucide-react`. Copyright Lucide Contributors; portions derive from Feather, copyright Cole Bemis. See the full notices distributed in `node_modules/lucide-react/LICENSE` and [Lucide's license](https://lucide.dev/license). These are compiled into local code; no icon CDN is contacted.

## Fonts

The app uses the visitor's system UI font stack. No font files are copied or downloaded at runtime.

## Supplied design reference

`design/reference-ui.png` is a user-supplied reference. No ownership or redistribution license is asserted for it. It is not included in `dist/` and is used only as visual direction. The supplied `CODEX_PROMPT.md` is preserved as project input.
